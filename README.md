#  Expense Tracker (Tkinter GUI)

A simple and efficient **GUI-based Expense Tracker** built with **Python Tkinter**.  
This app allows you to **add, view, and manage your daily expenses** with a clean interface and data storage in CSV format.

---

##  Features
-  Add expenses with a **date picker**
-  Enter **description & amount**
-  View expenses in a **tabular format**
-  Data saved in **`expenses.csv`** for persistence
- 🖥 User-friendly **Tkinter GUI**

---

##  Tech Stack
- **Language:** Python 3  
- **Libraries:**  
  - `tkinter` → GUI framework (comes with Python)  
  - `tkcalendar` → calendar date picker  
  - `csv` & `datetime` → expense storage and date handling
